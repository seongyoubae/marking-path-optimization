# Public input format

The included JSON contains synthetic endpoints generated by `python -m src.synthetic`; no industrial data is included.

```json
{
  "name": "two_part_example",
  "origin": [0, 0],
  "coords": [[2, 1], [5, 1], [4, 4], [7, 4]],
  "coords_paired": [[5, 1], [2, 1], [7, 4], [4, 4]]
}
```

- Each adjacent pair of `coords` rows represents one part's endpoints.
- `coords_paired` swaps those rows, making both directions available.
- Public inputs require at least two parts, finite nonnegative coordinates, a positive maximum coordinate and origin `[0, 0]`.
- Endpoints must be distinct and must not coincide with the origin, because the preserved SA initializer masks zero distances.
- The optimizer changes sequence and direction, not the geometry.

Keep a consistent coordinate unit within each input. The common evaluator exports both input-unit travel and dimensionless travel divided by the maximum scalar coordinate. These distances exclude the fixed entry-to-exit strokes.

Only publish geometry you are authorized to disclose. Local private inputs can be passed with `--input`; binary research datasets and result workbooks are ignored by default. The public loader uses JSON and does not deserialize pickle files.
